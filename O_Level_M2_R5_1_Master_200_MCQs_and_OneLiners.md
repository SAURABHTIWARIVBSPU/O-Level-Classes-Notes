# UNIT 1: Introduction to Web Design (Q1 — Q25)

**Q1. Who is widely regarded as the inventor of the World Wide Web (WWW)?**  
A) Vinton Cerf  
B) Tim Berners-Lee  
C) Brendan Eich  
D) Bill Gates  
**Answer:** B) Tim Berners-Lee  
**Explanation (हिन्दी + Eng):** Tim Berners-Lee ने 1989 में CERN (स्विट्जरलैंड) में WWW का आविष्कार किया था। Vinton Cerf को इंटरनेट का पिता कहा जाता है।

---

**Q2. What is the length of an IPv4 and IPv6 address respectively?**  
A) 16 bits and 32 bits  
B) 32 bits and 64 bits  
C) 32 bits and 128 bits  
D) 64 bits and 128 bits  
**Answer:** C) 32 bits and 128 bits  
**Explanation (हिन्दी + Eng):** IPv4 एड्रेस 32 बिट्स (4 बाइट्स) का होता है और डॉटेड डेसीमल में लिखा जाता है, जबकि IPv6 एड्रेस 128 बिट्स (16 बाइट्स) का हेक्साडेसीमल फॉर्मेट होता है।

---

**Q3. On which date was the public Internet officially launched in India?**  
A) 26th January 1950  
B) 15th August 1995  
C) 2nd October 2000  
D) 1st January 1990  
**Answer:** B) 15th August 1995  
**Explanation (हिन्दी + Eng):** भारत में आम जनता के लिए इंटरनेट 15 अगस्त 1995 को VSNL (विदेश संचार निगम लिमिटेड) द्वारा शुरू किया गया था।

**Q4. Which of the following switching techniques is used by the Internet?**  
A) Circuit Switching  
B) Packet Switching  
C) Message Switching  
D) Cell Switching  
**Answer:** B) Packet Switching  
**Explanation (हिन्दी + Eng):** इंटरनेट डेटा को छोटे-छोटे पैकेट्स (Packets) में विभाजित करके स्वतंत्र रास्तों से भेजता है, जिसे Packet Switching कहते हैं।

---

**Q5. What is the primary role of DNS (Domain Name System)?**  
A) To convert Domain Names to IP Addresses  
B) To design webpage layouts  
C) To secure data encryption  
D) To route emails  
**Answer:** A) To convert Domain Names to IP Addresses  
**Explanation (हिन्दी + Eng):** DNS इंटरनेट की फोनबुक की तरह काम करता है, जो याद रखने योग्य डोमेन नाम (जैसे `google.com`) को मशीन द्वारा समझे जाने वाले IP एड्रेस में बदलता है।

**Q9. Which meta tag is essential for enabling Responsive Web Design on mobile devices?**  
A) `<meta name="author">`  
B) `<meta name="viewport" content="width=device-width, initial-scale=1.0">`  
C) `<meta charset="UTF-8">`  
D) `<meta http-equiv="refresh">`  
**Answer:** B) `<meta name="viewport" content="width=device-width, initial-scale=1.0">`

**Q14. In TCP/IP architecture, which layer is responsible for end-to-end reliable data delivery?**

B) Transport Layer  
C) Internet Layer  
D) Network Access Layer  
**Answer:** B) Transport Layer  
**Explanation (हिन्दी + Eng):** Transport Layer पर काम करने वाला **TCP** प्रोटोकॉल डेटा के सही क्रम और त्रुटिरहित डिलीवरी (Error-free delivery) को सुनिश्चित करता है।

**Q15. In TCP 3-way handshake, what is the sequence of packets exchanged?**  
A) ACK -> SYN -> FIN  
B) SYN -> SYN-ACK -> ACK  
C) PING -> PONG -> ACK  
D) GET -> POST -> OK  
**Answer:** B) SYN -> SYN-ACK -> ACK  
**Explanation (हिन्दी + Eng):** क्लाइंट पहले SYN भेजता है, सर्वर SYN-ACK से उत्तर देता है, और क्लाइंट ACK भेजकर कनेक्शन स्थापित करता है।
