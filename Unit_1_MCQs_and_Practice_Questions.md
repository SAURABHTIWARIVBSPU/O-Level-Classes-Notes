# SECTION A: Topic-Wise Multiple Choice Questions (50 MCQs)

### 🔹 Topic 1: Introduction of Internet & History

**Q1. What was the predecessor of the modern Internet funded by the US Department of Defense?**  
A) NSFNET  
B) ARPANET  
C) ALOHANET  
D) USENET  
**Answer:** B) ARPANET  
**Explanation:** ARPANET (*Advanced Research Projects Agency Network*) was established in 1969 by the US DoD and was the first operational packet-switching network.

---

**Q2. Who are widely regarded as the "Fathers of the Internet" for co-designing the TCP/IP protocol suite?**  
A) Tim Berners-Lee and Robert Cailliau  
B) Vinton Cerf and Bob Kahn  
C) Bill Gates and Paul Allen  
D) Steve Jobs and Steve Wozniak  
**Answer:** B) Vinton Cerf and Bob Kahn  
**Explanation:** Vint Cerf and Bob Kahn invented the Transmission Control Protocol (TCP) and Internet Protocol (IP) in the 1970s.

---

**Q3. On which date was the public Internet officially launched in India for the first time?**  
A) 26th January 1990  
B) 15th August 1995  
C) 2nd October 2000  
D) 1st January 1998  
**Answer:** B) 15th August 1995  
**Explanation:** Videsh Sanchar Nigam Limited (VSNL) officially launched public Internet service in India on Independence Day, 15 August 1995.

---

**Q4. What is the total length of an IPv4 address and an IPv6 address respectively?**  
A) 16 bits and 32 bits  
B) 32 bits and 64 bits  
C) 32 bits and 128 bits  
D) 64 bits and 128 bits  
**Answer:** C) 32 bits and 128 bits  
**Explanation:** IPv4 addresses are 32 bits (4 octets / 4 bytes) long, whereas IPv6 addresses are 128 bits (16 bytes) long.

---

**Q5. Which switching technique is utilized by the Internet to transmit data?**  
A) Circuit Switching  
B) Packet Switching  
C) Message Switching  
D) Cell Switching  
**Answer:** B) Packet Switching  
**Explanation:** The Internet divides data streams into individual discrete packets that travel through various network routes independently using Packet Switching.

---

**Q6. Which protocol is connection-oriented and ensures reliable, error-checked data delivery over the Internet?**  
A) UDP  
B) IP  
C) TCP  
D) ICMP  
**Answer:** C) TCP  
**Explanation:** TCP (Transmission Control Protocol) establishes a 3-way handshake connection and guarantees that data arrives in order without loss or duplicates.

### 🔹 Topic 2: World Wide Web (WWW) & W3C

**Q7. In which year and at which organization did Tim Berners-Lee invent the World Wide Web?**  
A) 1983 at DARPA  
B) 1989 at CERN  
C) 1995 at W3C  
D) 1991 at MIT  
**Answer:** B) 1989 at CERN  
**Explanation:** British scientist Sir Tim Berners-Lee invented the World Wide Web in 1989 while working at CERN (Switzerland).

---

**Q8. What does W3C stand for in the context of web design?**  
A) World Wide Web Community  
B) World Wide Web Consortium  
C) World Web Design Committee  
D) World Wide Web Corporation  
**Answer:** B) World Wide Web Consortium  
**Explanation:** W3C (*World Wide Web Consortium*) is the international standards organization for the World Wide Web, founded in 1994 by Tim Berners-Lee.

---

**Q9. What is the fundamental difference between the Internet and the World Wide Web (WWW)?**  
A) They are identical terms.  
B) The Internet is a service on the WWW.  
C) The Internet is the physical network infrastructure; the WWW is an application-layer service built on it.  
D) WWW is hardware, whereas the Internet is software.  
**Answer:** C) The Internet is the physical network infrastructure; the WWW is an application-layer service built on it.  
**Explanation:** The Internet is the underlying network of computers and physical connections; WWW is an information sharing service using HTTP and HTML that operates on top of the Internet.

---

**Q10. What is the default port number used by unencrypted HTTP and encrypted HTTPS respectively?**  
A) Port 21 and Port 22  
B) Port 25 and Port 110  
C) Port 80 and Port 443  
D) Port 8080 and Port 8443  
**Answer:** C) Port 80 and Port 443  
**Explanation:** HTTP communicates by default on TCP Port 80, while secure HTTPS uses TCP Port 443 with TLS/SSL encryption.

---

**Q11. Which part of the URL `https://www.example.org:8080/notes/web.html` represents the protocol scheme?**  
A) `example.org`  
B) `https`  
C) `8080`  
D) `/notes/web.html`  
**Answer:** B) `https`  
**Explanation:** In a URL, the substring preceding `://` defines the protocol scheme (e.g., `http`, `https`, `ftp`).

---

**Q12. What is the relationship between URI, URL, and URN?**  
A) Every URI is a URL.  
B) Every URL is a URI, but not every URI is a URL.  
C) URN and URL are completely unrelated to URI.  
D) URI only refers to email addresses.  
**Answer:** B) Every URL is a URI, but not every URI is a URL.  
**Explanation:** URI (*Uniform Resource Identifier*) is the overarching identifier category; URL (*Locator*) and URN (*Name*) are specific subsets of URI.

### 🔹 Topic 4: Working of Websites, DNS & HTTP

**Q16. What is the primary role of the DNS (Domain Name System)?**  
A) To translate IP addresses into MAC addresses  
B) To translate human-readable domain names into machine-readable IP addresses  
C) To encrypt web browser traffic  
D) To format HTML pages  
**Answer:** B) To translate human-readable domain names into machine-readable IP addresses  
**Explanation:** DNS functions as the internet's address book, converting domain names like `google.com` to IP addresses like `142.250.190.46`.

---

**Q17. Which steps constitute the TCP 3-Way Handshake?**  
A) PING -> PONG -> ACK  
B) SYN -> SYN-ACK -> ACK  
C) REQ -> RES -> CLOSE  
D) HELLO -> AUTH -> OK  
**Answer:** B) SYN -> SYN-ACK -> ACK  
**Explanation:** TCP establishes connection using Synchronize (SYN), Synchronize-Acknowledge (SYN-ACK), and Acknowledge (ACK) packets.

---

**Q18. What does an HTTP 404 status code indicate?**  
A) OK / Success  
B) Internal Server Error  
C) Resource Not Found (Client Error)  
D) Permanent Redirect  
**Answer:** C) Resource Not Found (Client Error)  
**Explanation:** HTTP 404 indicates that the client was able to communicate with the server, but the server could not locate the requested resource.

---

**Q19. Which HTTP response code series represents Server-Side Errors?**  
A) 1xx  
B) 2xx  
C) 4xx  
D) 5xx  
**Answer:** D) 5xx  
**Explanation:** 5xx codes (e.g., 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable) represent server errors.

---

**Q20. Which HTTP method is typically used when submitting sensitive user data such as passwords and credit card forms?**  
A) GET  
B) POST  
C) HEAD  
D) OPTIONS  
**Answer:** B) POST  
**Explanation:** POST sends form data inside the HTTP request body rather than appending it to the visible URL query string, making it suitable for submitting confidential data.

---

**Q21. What happens during the browser's Rendering Pipeline after receiving HTML and CSS?**  
A) DOM Tree and CSSOM Tree are constructed, merged into a Render Tree, then Layout and Paint occur.  
B) Server compiles JavaScript to machine code.  
C) Database queries are executed on the client machine.  
D) The IP address is converted to a MAC address.  
**Answer:** A) DOM Tree and CSSOM Tree are constructed, merged into a Render Tree, then Layout and Paint occur.  
**Explanation:** The browser engine parses HTML to build the DOM, parses CSS to build CSSOM, combines them into the Render Tree, performs layout geometry, and paints pixels.

### 🔹 Topic 5: Front End vs. Back End

**Q22. Which trio of core technologies forms the foundation of Front End Web Development?**  
A) PHP, MySQL, Apache  
B) HTML, CSS, JavaScript  
C) Python, Django, PostgreSQL  
D) Java, Spring, Oracle  
**Answer:** B) HTML, CSS, JavaScript  
**Explanation:** HTML provides content structure, CSS defines visual styling, and JavaScript enables interactivity on the client side.

---

**Q23. Where does Front End code execute?**  
A) On the remote web hosting server  
B) Inside the user's local Web Browser (Client machine)  
C) Inside the database engine  
D) Inside the DNS resolver  
**Answer:** B) Inside the user's local Web Browser (Client machine)  
**Explanation:** Front-end assets (HTML, CSS, JavaScript) are downloaded and executed locally inside the client's web browser.

---

**Q24. Which of the following is exclusively a Back End technology / runtime?**  
A) HTML5  
B) CSS3  
C) Node.js / PHP  
D) Canvas API  
**Answer:** C) Node.js / PHP  
**Explanation:** Node.js, PHP, Python, and Java execute on the server to handle database operations, business logic, and authentication.

**Q25. Can a user view the original server-side PHP or Python source code by clicking "View Page Source" in a browser?**  
A) Yes, all source code is always visible in the browser.  
B) No, the server processes the script and sends only the rendered output (HTML/CSS/JS) to the client.  
C) Only if the browser is Google Chrome.  
D) Only if HTTPS is disabled.  
**Answer:** B) No, the server processes the script and sends only the rendered output (HTML/CSS/JS) to the client.  
**Explanation:** Server-side scripts execute exclusively on the server; the client only receives the final generated HTML response.

### 🔹 Topic 6: Client-Side vs. Server-Side Scripting

**Q26. Which of the following is the standard Client-Side Scripting language supported by all modern web browsers?**  
A) PHP  
B) Ruby  
C) JavaScript  
D) Perl  
**Answer:** C) JavaScript  
**Explanation:** JavaScript (ECMAScript) is the universal client-side programming language supported natively across all modern web browsers.

**Q27. What is a major advantage of Client-Side form validation compared to Server-Side validation?**  
A) It provides absolute impenetrable database security.  
B) It gives immediate instant feedback to the user without requiring a server round-trip.  
C) It works even if JavaScript is disabled in the browser.  
D) It encrypts all data automatically.  
**Answer:** B) It gives immediate instant feedback to the user without requiring a server round-trip.  
**Explanation:** Client-side validation checks inputs instantly in the browser, improving UX and reducing unnecessary server load.

---

**Q28. Why is Server-Side validation mandatory even if Client-Side validation is implemented?**  
A) Because client-side validation can be easily bypassed or disabled by users/attackers.  
B) Because browsers cannot execute regular expressions.  
C) Because HTML5 inputs do not support validation.  
D) Because CSS cannot style error messages.  
**Answer:** A) Because client-side validation can be easily bypassed or disabled by users/attackers.  
**Explanation:** Client-side scripts can be manipulated or bypassed (e.g., using Postman or disabling JS), so the server must validate all data for security.

### 🔹 Topic 7: Responsive Web Designing (RWD)

**Q30. Who coined the term "Responsive Web Design" in his seminal 2010 article?**  
A) Tim Berners-Lee  
B) Brendan Eich  
C) Ethan Marcotte  
D) Håkon Wium Lie  
**Answer:** C) Ethan Marcotte  
**Explanation:** Ethan Marcotte introduced Responsive Web Design (RWD) in May 2010.

---

**Q31. Which meta tag is essential in the `<head>` of an HTML document to enable proper mobile responsive scaling?**  
A) `<meta name="keywords" content="web, design">`  
B) `<meta name="viewport" content="width=device-width, initial-scale=1.0">`  
C) `<meta http-equiv="refresh" content="30">`  
D) `<meta name="author" content="NIELIT">`  
**Answer:** B) `<meta name="viewport" content="width=device-width, initial-scale=1.0">`  
**Explanation:** The viewport meta tag instructs mobile browsers to match screen dimensions to device width rather than defaulting to a virtual 980px desktop viewport.

---

**Q32. What are the three core technical components of Responsive Web Design?**  
A) HTML, XML, JSON  
B) Fluid Grids, Flexible Images, and CSS3 Media Queries  
C) PHP, MySQL, Apache  
D) Java, Applets, Flash  
**Answer:** B) Fluid Grids, Flexible Images, and CSS3 Media Queries  
**Explanation:** RWD relies on fluid proportion-based grids, auto-scaling media/images, and CSS media queries.

---

**Q33. Which CSS rule ensures that an image scales down dynamically on smaller screens without overflowing its container?**  
A) `img { width: 1000px; }`  
B) `img { max-width: 100%; height: auto; }`  
C) `img { display: none; }`  
D) `img { position: fixed; }`  
**Answer:** B) `img { max-width: 100%; height: auto; }`  
**Explanation:** Setting `max-width: 100%` and `height: auto` ensures the image scales down proportionally to fit smaller parent containers while preserving aspect ratio.

---

**Q34. In CSS3, which feature allows different style rules to be applied based on screen size, resolution, and orientation?**  
A) CSS Transitions  
B) CSS Keyframes  
C) CSS Media Queries (`@media`)  
D) CSS Variables  
**Answer:** C) CSS Media Queries (`@media`)  
**Explanation:** Media queries (`@media screen and (min-width: 768px) { ... }`) apply conditional styling based on viewport width, screen resolution, and orientation.

---

**Q35. What is the "Mobile-First" design strategy?**  
A) Designing exclusively for Apple iPhones.  
B) Writing base CSS styles for mobile devices first, then enhancing layout for larger screens using `min-width` media queries.  
C) Blocking desktop users from accessing the website.  
D) Converting web pages into downloadable APK files.  
**Answer:** B) Writing base CSS styles for mobile devices first, then enhancing layout for larger screens using `min-width` media queries.  
**Explanation:** Mobile-First builds a lightweight core for mobile screens first and progressively layers advanced styling for larger screens.

### 🔹 Topic 8: Static vs. Dynamic Websites

**Q36. In a Static Website, what happens when a client requests a page?**  
A) The server creates and calculates custom HTML using a database query.  
B) The server sends the exact pre-stored HTML/CSS file directly to the client without on-the-fly computation.  
C) The client must compile the code using a local C++ compiler.  
D) The database generates a PDF document.  
**Answer:** B) The server sends the exact pre-stored HTML/CSS file directly to the client without on-the-fly computation.  
**Explanation:** Static sites serve pre-built files stored on the server filesystem directly to every client.

---

**Q37. Which of the following is a characteristic of a Dynamic Website?**  
A) Content changes based on user interactions, database records, and session data.  
B) Pages are created on-the-fly using server-side programming.  
C) Content can be updated easily via Content Management Systems (CMS) without editing code.  
D) All of the above.  
**Answer:** D) All of the above.  
**Explanation:** Dynamic websites generate customized content using server scripts and databases, and allow easy updates via CMS portals.

---

**Q38. Which type of website is typically faster to deliver and requires the least server computational power?**  
A) Dynamic Website  
B) Static Website  
C) Database-driven Web App  
D) Enterprise E-Commerce Portal  
**Answer:** B) Static Website  
**Explanation:** Because static HTML/CSS files require no backend processing or database queries, they are delivered instantly with minimal server overhead.

---

**Q39. Which of the following is an example of a Dynamic Website?**  
A) A 1-page personal resume built only with HTML and CSS  
B) An e-commerce platform like Amazon / Flipkart with user carts and personalized recommendations  
C) A static restaurant menu with plain HTML text  
D) A plain text privacy policy page  
**Answer:** B) An e-commerce platform like Amazon / Flipkart with user carts and personalized recommendations  
**Explanation:** E-commerce stores customize content, search queries, inventory, and cart states dynamically using databases and backend scripts.

---

**Q40. What does CMS stand for in web publishing?**  
A) Computerized Media System  
B) Content Management System  
C) Cascading Management Server  
D) Client Markup Standard  
**Answer:** B) Content Management System  
**Explanation:** CMS (*Content Management System*, like WordPress, Drupal, Joomla) enables non-technical users to create, manage, and modify website content.

**Q42. In a URL, what does the fragment identifier prefixed with `#` (e.g., `#contact`) indicate?**  
A) The password for server access  
B) A specific named anchor / element ID within the webpage  
C) The port number of the server  
D) A server error code  
**Answer:** B) A specific named anchor / element ID within the webpage  
**Explanation:** The hash `#` followed by an identifier tells the browser to scroll directly to the HTML element with that matching `id`.

**Q43. Which protocol is primarily used for uploading files from a local computer to a remote web server?**  
A) SMTP  
B) FTP (File Transfer Protocol)  
C) SNMP  
D) POP3  
**Answer:** B) FTP (File Transfer Protocol)  
**Explanation:** FTP (and secure SFTP) is designed specifically for bidirectional file transfers between client and server.

---

**Q44. What is the HTTP 301 status code?**  
A) Bad Request  
B) Unauthorized  
C) Moved Permanently (Permanent Redirect)  
D) Gateway Timeout  
**Answer:** C) Moved Permanently (Permanent Redirect)  
**Explanation:** HTTP 301 informs search engines and browsers that the requested resource has been permanently moved to a new URL.

**Explanation:** `.http` is a protocol scheme, not a valid Top-Level Domain name (TLD).

**Q46. Which protocol is used by email clients to send outgoing emails to mail servers?**
